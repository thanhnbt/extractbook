# Phase 1.2 — Thesis & Argument Tree

## Prompt
```
Cuốn "{{BOOK_TITLE}}" của {{AUTHOR}}.

### 1. THESIS CHÍNH
- Luận điểm trung tâm của cuốn sách là gì? (1-2 câu)
- Tác giả muốn thay đổi quan điểm gì ở người đọc?
- Confidence: 🟢/🟡/🔴

### 2. CÂY LẬP LUẬN
Vẽ cây từ thesis → supporting arguments → evidence:

Thesis: [...]
├── Luận điểm 1: [...] (Confidence: 🟢/🟡/🔴)
│   ├── Evidence: [...] 
│   └── Evidence: [...]
├── Luận điểm 2: [...] (Confidence: 🟢/🟡/🔴)
│   └── Evidence: [...]
└── ...

### 3. PHẢN LUẬN
- Tác giả có address phản luận nào?
- Cách xử lý: bác bỏ / thừa nhận / tích hợp?

### 4. FRAMEWORK / MODEL
Tác giả có đưa ra framework/model riêng không?
(VD: "5 forces" của Porter, "7 habits" của Covey)
Nếu có, mô tả chi tiết framework đó.

Quy tắc:
- Phân biệt rõ giữa "tác giả nói" vs "tôi suy luận"
- Nếu không nhớ evidence cụ thể, ghi "[evidence không nhớ]"
```
